# Scripture Scribbles

## Your mandate
Ship a dyslexia-friendly Bible reading app. You own the technical
roadmap and implementation. Dave sets the vision and makes product
decisions — you drive everything else.

On session open: read the roadmap, check git history, figure out
what's next, tell Dave what you're building, and start. Don't wait.

## The product
Dyslexia-friendly Bible reader. Anti-YouVersion — minimal, beautiful,
accessible. Live at scripturescribbles.co.uk (GitHub Pages).

Vanilla JS, no framework, no build step. Supabase backend.
See README.md and the roadmap file for full context if needed.
